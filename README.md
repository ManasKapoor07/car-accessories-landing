# 🎨 CarVatika – Frontend

Frontend application for **CarVatika**, a premium automotive accessories platform.  
Designed with a **dark, high-end UI**, focused on clean UX, performance, and conversion.

This repository contains the **user-facing web application** that consumes the Spring Boot backend APIs.

---

## 🌐 Overview

- Premium automotive e-commerce experience
- Dark theme with minimal, modern aesthetics
- Responsive and component-driven UI
- Integrated with JWT-secured backend APIs

---

## ⚙️ Tech Stack

- **Framework:** React / Next.js
- **Styling:** Tailwind CSS / Custom CSS
- **State Management:** Context API / Redux (if used)
- **Authentication:** JWT (via backend)
- **Deployment:** Vercel
